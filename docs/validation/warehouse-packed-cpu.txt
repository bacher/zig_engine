Warehouse packed presentation CPU source benchmark, 2026-11-15
Native arm64, Zig ReleaseFast.
Command: ZIG_GLOBAL_CACHE_DIR=/private/tmp/warehouse-zig-global zig build bench-packed-geometry -Doptimize=ReleaseFast -j2

Scope: 4096 complete logical client records, each with 150 stored units. Only
observed objects enter the spatial presentation directory. This measures CPU
source bookkeeping and geometry derivation, not authoritative simulation throughput.
Times are wall-clock averages across eight complete source sweeps. Idle scans
check dirty flags across 10000 unchanged frames and derive/upload nothing.
Directory time is cumulative initial directory construction; seeding records is excluded.

source_bytes counts CPU Face(20B), Instance(16B), Marker(20B) records per complete
sweep. Actual GPU records additionally carry their source owner and are measured
separately by packed_renderer. This benchmark performs no GPU uploads or draws.
retained_directory_estimate includes hash/list capacities and retained pallet indices,
excluding the client logical records. transient_source_capacity is the maximum live
heap capacity of one rebuilt source, excluding fixed stack masks and allocator metadata.
boundary=true crosses chunk X/Y/Z boundaries; the first warehouse crosses wrapped X.
